▾ About This Report

Upload the same two Business Central exports for a lot — Origin → Usage and Usage → Origin — and this turns them into five report views instead of one flat spreadsheet: where the lot came from, every production order that repacked it, a per-SKU rollup, every sales shipment, and what's still on hand by location.

Origins — the purchase receipt(s) or production order(s) this lot's whole trace traces back to.
Production Detail — every production order that repacked this lot into something else, grouped by what it became.
SKU Summary — one row per item touched, with what was produced / transferred / sold / consumed / remains.
Sales Shipments — every shipment out the door, by customer.
SKU by Location — current on-hand position, broken out by warehouse/location.

Pulling a trace from Business Central

  1. 1
    Log in to Business Central with your EBE O365 credentials at businesscentral.dynamics.com/WholeAndFree-Prod.
  2. 2
    Open Item Tracing. Click the search (magnifying glass) icon in the top right, type "Item Tracing," and select the Item Tracing task.
  3. 3
    Enter the Lot No. Every trace has to start from a lot number.
  4. 4
    Set the direction and trace. Set Trace Method to "Origin → Usage" or "Usage → Origin," set Show Components to "No," then click Trace.
  5. 5
    Export it. Click the export icon (box with an arrow) and choose Open in Excel.
  6. 6
    Do it again for the other direction, then upload both files below.

Tip: personalize the Item Tracing columns first so Entry Type, Source Type, Source Name, Lot No., and Posting Date are all showing — that's what this tool reads from the export.
